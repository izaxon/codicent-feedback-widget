Codicent Issue Widget — demo

Prototyp. Med demo: true (och utan endpoint) kör widgeten i demo-läge: inget skickas, meddelandet loggas i webbläsarkonsolen och visas här under.

Ljud: tryck på Spela in ljud i widgeten (mikrofonen frågas först då). Du får tidsräknare (max 2 min), uppspelning innan du skickar, och kan ta bort/spela in igen. Efter skick visas bifogat filnamn här under. Enbart text går också bra. Webbläsarens tal-till-text är bara en valfri ifyllnadshjälp — ljudfilen är det som bifogas och gäller.

1. Enklaste embed (data-attribut, ett projekt)

<div data-codicent-issue-widget
     data-project="nextphase"
     data-demo="true"   <!-- bara för demo: utan endpoint skickas inget -->
     data-button-text="Rapportera ett problem"></div>
<script src="widget.js"></script>

2. Flera projekt + CSS-anpassning

Besökaren får en dropdown eftersom allowProjectSwitch är på och två projekt anges. Färger/radie/font styrs bara via CSS-variabler ovan.

3. JS-config (så här sätter hosten endpoint + nyckel i praktiken)

Nyckeln nedan är en platshållare. Nyckeln definieras/registreras i Codicent som ett meddelande taggat #api-key (endast SHA-256-hash av värdet lagras där). I produktion injicerar host-appen endpoint + nyckelvärdet från sin hemliga config vid sidladdning — aldrig en riktig nyckel incheckad i frontendkoden. Se README > Säkerhet.

window.CodicentIssueWidget.init({
  mount: '#js-config-mount',
  project: 'nextphase',
  endpoint: 'https://EXEMPEL.invalid/codicent/issue-drafts', // TODO: Codicents riktiga endpoint
  apiKey: '__HOST_INJECTED_ISSUE_WIDGET_KEY__'              // värdet för nyckeln registrerad med #api-key i Codicent; scoped + återkallbar
});

4. Engelska + egen adapter (lang, send)

lang: 'en' byter alla texter och taligenkänningens språk; send ersätter adaptern så att hosten slipper forka widget.js. Här returnerar den bara ett påhittat id.

window.CodicentIssueWidget.init({
  mount: '#en-mount',
  project: 'nextphase',
  lang: 'en',
  privacyUrl: 'https://example.com/privacy',
  send: async (payload, config, audio) => ({ ok: true, id: '…' })
});
